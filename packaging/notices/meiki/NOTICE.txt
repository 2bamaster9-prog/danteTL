DanteJP includes three unmodified MeikiOCR ONNX model files by rtr46.
Their pinned upstream model cards declare LGPL-3.0. The inference Python package
has its own Apache-2.0 license, preserved in its installed .dist-info directory.

Detection:
https://huggingface.co/rtr46/meiki.text.detect.v0/tree/a9cffa4f60cbf72ddb87edf19c6f98a01cd042e6
  meiki.text.detect.v0.1.960x544.onnx
  Original inference.v0.1.960x544.py is reproduced as inference.detection.py.txt.

Recognition:
https://huggingface.co/rtr46/meiki.txt.recognition.v0/tree/a28cf5874dc2438ebb1c86336be26bcec51e3375
  meiki.text.rec.v0.960x32.onnx
  meiki.text.rec.v0.vertical.32x480.onnx
  Original inference.py is reproduced as inference.recognition.py.txt.

These original model graphs/weights are distributed in the same ONNX form as
upstream, with the pinned model cards and available inference source here.
See COPYING.LESSER.txt and COPYING.txt for the license texts. No warranty is given.

The models are separate files in _internal/app/models/meiki. Integrity hashes,
revisions and sizes appear in dantejp/ocr/models.py inside the standard application
wheel under _internal/app/application. Wheels are ZIP archives; the application
source, model validation, paths and loader can be inspected and modified there.
There is no restriction on
modifying/replacing these components or reverse engineering to debug modifications.
DANTEJP_MODEL_DIR selects an explicit model directory. Modified model hashes
must also be updated in models.py; the default loader checks the pinned hashes.
Normal Verify / repair keeps the app's resources unchanged and writes to AppData.
