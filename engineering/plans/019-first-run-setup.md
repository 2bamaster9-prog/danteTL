# Slice 019: First-run setup and download visibility

- Offer a skippable guide on a fresh app: welcome, model choice, detected acceleration, review,
  explicit downloads, completion/restart. Existing prepared installations remain uninterrupted.
- Keep CPU available, manual overrides persistent during hardware detection, and GPU advice honest.
- Reuse model verification/downloads, isolated runtime installation and existing first-use consent.
- Persist skip/completion and pending post-restart model intent separately from committed selection.
- Show setup stages plus real current-file bytes; label unavailable totals without inventing progress.
- Verify cancel/retry/drain, corrupt downloads, cached reuse, native layout, the packaged installer
  and restart, and the fresh EXE without Python on PATH. Preserve shared CUDA versions and models.

No automatic downloads, driver installation, new model support or conventional installer.
Evidence and limits are recorded in [verification](../verification.md).
